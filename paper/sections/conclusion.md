## 6. Conclusion

One compromised agent can lock a research swarm into a false result, but only with an exploit each victim's own
test appears to confirm, and only if no correction arrives in time. The blast radius is set by correction, not
infection. Swarms built today should give some agent or service the job of checking claims before they are
adopted or promoted, and keep open the channels a warning travels by.
